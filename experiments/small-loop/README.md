# PCB Golf-inspired single-channel demo

This is a deliberately reduced 15-component, 11-net, two-layer circuit, **not a PCBGolf challenge submission**. Original source is commaai/PCBGolf `7210bdb5049c5b7fdf4900a34928e2736767292a`. Preserve that source and all previous experiments.

Q2's two common-source MOSFETs, R78/R98 gate pull-downs, R90/R91 load resistors, and R82/R83 + LED10 indicators retain the original channel topology. R19 exposes the original sense branch. J4's original 2×4 physical connector is deliberately repurposed: 1/8 ground, 2/7 external regulated 5V, 3 IGN control, 4 RELAY control, 5 externally biased CH1_SBU1 load, 6 external sense input. Control inputs require an external driver capable of supplying the original LED indicator current; this board contains no MCU. The switched load is external; it is not silently removed. LED6/R74 indicate the external 5V supply; C5/C46/C50 bypass it. These three capacitors and supply indicator originally belonged to the larger power system and now share the external supply. CAN, USB, regulators, MCU and the other channels are deliberately absent. Do not connect J4 to the original CAN harness: the pinout is different.

Electrical function follows the original channel; fabrication DRC does not prove load ratings, thermal performance, EMI or powered hardware operation. No such qualification is claimed. The layout has a 52×38 mm rectangular envelope and two copper layers. The original bare board had no qualified fixed outline; no claim of original mechanical product compatibility is made.

## Authoritative checks

All original `.kicad_pro` DRC rules/severities, ERC matrix/severities, exclusions and Default netclass are preserved. Original minimum width is **0.1016 mm**, Default nominal width **0.20 mm**, effective Default clearance **0.20 mm**, via **0.60/0.30 mm**. Experiments additionally require every produced trace to be at least the nominal **0.20 mm**. There are no source custom `.kicad_dru` files. Electrical land patterns are unchanged; only the original undersized LED6 silk polarity mark is enlarged to satisfy its existing silk requirements.

KiCad native saving can overwrite project settings even when only the PCB is saved. `campaign.py` preserves producer-written project bytes as evidence and restores the authoritative project after each subprocess, before native evaluation. Never trust the post-save project without checking it. `audit.py` independently compares saved PCB net partitions, every original retained electrical pad geometry, source rules, native connectivity and DRC. Cost zero requires all gates. Wire length and via count are separate metrics.

Each placement action swaps actual components based on current net groups and geometric span. Full-board routing starts with a declared fresh copper realization from the candidate placement. Input and preview contain no inherited vias; newly routed via identities/dimensions are checked. No prior routed board is modified or used as a hidden placement solution. Failed routing is not infeasibility proof.

The higher-loop protocol is written before any measured candidate run. Equal three-decision arms compare all-net HPWL ranking with signal-only HPWL ranking. Both start at the same seed713 layout and use the same full-board routing control and per-decision 60s/30-pass/one-thread cap. Native full-board fanout is disabled because that optional preprocessing produced 0.15mm traces despite a 0.20mm DSN width. Routing still covers every net on both layers. The primary metric is retained feasibility cost@3, ties keep baseline. Routed wire length determines lower-loop retention only after feasibility ties; it cannot be turned into a higher-level policy win.

## Local reproduction

Use the existing Copperhead Python environment (sexpdata) and the paths to KiCad10/Freerouting2.4.1 in the scripts. `build_input.py SOURCE OUT` creates a deterministic schematic and filtered board; `native_input.py SOURCE OUT` realizes the board under KiCad Python. Restore the generated authoritative project after native saving, then move the intermediate filtered board outside the project before JITX import. Supply relative footprint libraries to every native project.

`campaign.py --base /absolute/runtime --source /absolute/frozen/pcbgolf-source` requires a saved accepted `feasible-width200/acceptance.json` and the source-bound input manifest. All outputs go to a new `campaign/` and existing evidence is not overwritten. The full-board realization reuses `scripts/copperhead_route.py` from Copperhead479bb4e.

JITX import needs a directory with exactly one PCB and corresponding schematic/project, plus a pre-existing output Python package. File arguments gave misleading missing-PCB errors in this installed importer. The isolated runtime design is `small_loop.design.SmallLoopInput`. Successful import/build is not rule parity. Imported rules omit effective netclass clearance and do not carry native ERC matrices, DRC severities/exclusions or library checks. Explicit JITX source restores the 0.20mm routing/spacing and original via definition; native KiCad remains authoritative for acceptance. JITX uses normalized net names and may approximate copper/mask shapes; its exported geometry must be audited, never substituted for the native accepted board without validation.
