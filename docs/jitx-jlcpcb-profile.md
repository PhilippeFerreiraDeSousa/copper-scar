Its downloaded wheel SHA256 is `a93489a0bc816bb62b57da732bcef7b36372bff9eebefd0f9eda244303c89e01`. It was installed without changing its dependencies. The official GitHub skills reference these substrates, but a public source repository for this package was not located; do not invent a GitHub commit. Official source is published in the [JITX profile documentation](https://docs.jitx.com/en/4.0/_modules/jitxlib/jlcpcb/rules.html).

The profile explicitly targets **1 oz copper, four to six layers**. It is not a drop-in two-layer fabrication profile. The present two-layer experiments remain separate and unqualified. Its named four-layer substrate, materials and via definitions can be reused for a four-layer proposal. Existing default trace/differential routing structures are not automatically evidence of USB impedance, current capacity or signal integrity. [JITX substrate source](https://docs.jitx.com/en/latest/_modules/jitxlib/jlcpcb/JLC04161H_1080.html).

Current JLCPCB capabilities distinguish 1 oz two-layer 0.10 mm trace/space from multilayer 0.09 mm. Original 0.1016 mm track minimum and 0.2 mm default netclass clearance remain stricter. Current common-color 1 oz mask bridge is 0.10 mm, exceeding the profile's 0.08 mm; black/white require 0.13 mm. PTH-to-track, NPTH-to-track and via-to-track have different minima, so the profile's single hole-clearance value is incomplete. Multilayer PTH annular ring absolute minimum is 0.15 mm. Silkscreen guidance is 0.15 mm line width, 1 mm height and 0.15 mm pad separation. [JLCPCB manufacturing capabilities](https://jlcpcb.com/capabilities/pcb-capabilities).

JLCPCB currently lists JLC04161H-1080 with outer copper 0.035 mm, inner copper 0.0152 mm, 0.0764 mm prepreg on each side of a 1.265 mm core. The package uses 0.0175 mm inner copper for this named stackup. The local derived proposal corrects that discrepancy. Manufacturer dielectric and coating assumptions must also be retained when calculating impedance. [JLCPCB controlled-impedance stackups](https://jlcpcb.com/impedance).

## Reuse implementation and gaps

`pcbgolf_import/fabrication.py` derives from the official substrate and rules, reusing materials and via definitions. It preserves original stricter trace width, applies the measured 0.05 mm generation-only clearance guard, raises mask bridge to 0.102 mm, and applies conservative generation limits for hole clearance and annular ring. Original KiCad rules remain mandatory. The derived stackup corrects inner copper to the primary manufacturer's value. The separate `JLCProfileProbe` dry-build verifies Python translation; it is not a routed or fabrication-qualified board.

The guard margin is an exporter experiment to meet a fixed physical requirement. It is not an optimization objective and must never migrate into a looser acceptance threshold. Exported legacy board `net_class` blocks must be removed before source-rule checking: otherwise they override the original project and silently change effective rules.

Before promoting this four-layer proposal, add independent checks for the manufacturing profile alongside the original stricter requirements, including type-specific holes, slots, mask colors/process, board edges, all-layer copper, and via-in-pad process. Preserve and verify through-via geometry; package via names alone are not manufacturing evidence. Do not assert that original-project DRC alone covers the added fabrication requirements.

Electrical constraints remain separate: power rail currents and voltage drop, thermal paths, return planes, USB differential impedance and skew, clock/decoupling placement, CAN routing and termination, and connector access/envelopes. The inherited 90-ohm structure's nominal 0.09 mm geometry conflicts with stricter original width/spacing requirements; it must be recalculated for a permitted geometry, not blindly selected.

Bare-board manufacture is also distinct from assembly. Parts, package pitches, supported processes, tooling edges, placement access, component height and mating access require the final assembly to be checked. Choosing a standard stackup does not qualify these. [JLCPCB assembly capabilities](https://jlcpcb.com/capabilities/pcb-assembly-capabilities).
